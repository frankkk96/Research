# Arm 公司概览 — 发展沿革 · 关键事件 · 关键人物 · 关键产品

> 整理于 2026-07-15。公开资料整理,非投资建议。
> 一句话画像:Arm 是全球移动/嵌入式 CPU 指令集的事实标准。它不自己造芯片(直到 2026 年首次例外),而是把 CPU 架构与 IP 授权给全球芯片厂商,靠**授权费(Licensing)+ 每颗芯片的版税(Royalty)** 赚钱——全球累计已有超 3,000 亿颗 Arm 芯片出货。

---

## 一、发展沿革(时间线)

| 时间 | 事件 | 意义 |
|---|---|---|
| 1985 | Acorn 公司的 Steve Furber、Sophie Wilson 设计出第一颗 ARM 处理器 **ARM1** | Arm 架构的技术原点(早于公司成立) |
| **1990.11** | **Advanced RISC Machines Ltd 成立**,Acorn + Apple + VLSI Technology 三方合资 | 公司正式诞生;Apple 出资约 300 万美元,Acorn/Apple 各约 43% 股权 |
| 1991 | Robin Saxby 出任首任 CEO,确立**"只卖 IP、不造芯片"的授权商业模式** | 定义了 Arm 至今的核心打法 |
| 1993 | Arm 架构进入 Apple Newton;后被 Nokia/TI 用于手机 | 打开移动市场,ARM7TDMI 成为一代经典 |
| **1998.04.17** | 更名 **ARM Holdings plc**,在**伦敦交易所 + 纳斯达克双重上市** | 首次成为公众公司 |
| 2004 | 以约 9.13 亿美元收购 **Artisan**(物理 IP:标准单元库、存储编译器) | 补齐物理 IP,切入代工生态 |
| 2005–2004 | 推出 **Cortex** 品牌:Cortex-A(应用)/-R(实时)/-M(微控制) | 产品线现代化,统治智能手机与 IoT |
| 2006 | 收购 Falanx,发展 **Mali GPU** 产品线 | 从 CPU 扩展到 GPU |
| **2016.07** | **软银(SoftBank)以约 320 亿美元收购 Arm 并私有化退市** | 孙正义押注"物联网时代的入口";Arm 转向长期、重研发投入 |
| 2018.10 | 推出面向数据中心的 **Neoverse** 平台 | 正式进军服务器/云,埋下日后 AI 增长的伏笔 |
| **2020.09** | **英伟达(Nvidia)同意以约 400 亿美元从软银收购 Arm** | 若成功将重塑半导体格局 |
| **2022.02** | **英伟达收购案因全球监管阻力告吹**;同月 **Rene Haas 接任 CEO** | 转向重新 IPO;Haas 主导后续复兴 |
| 2022 | 将 Arm 中国股权转入独立实体,结束与前 CEO 吴雄昂的控制权纠纷 | 为 IPO 扫清"财报并表"障碍(见 `risk/china.md`) |
| **2023.09** | **重返资本市场,在纳斯达克 IPO**,估值约 545 亿美元(当年最大 IPO) | 软银仍保留约 90% 股份;上市代码 ARM |
| 2025.04 | 宣布把 **Artisan 物理 IP 业务出售给 Cadence**(2026.01 完成交割) | 战略聚焦:退出低差异化的物理 IP,集中于 CPU 平台 |
| **2026.03** | "Arm Everywhere"大会发布 **Arm AGI CPU**——公司史上**首颗自研量产芯片**,与 Meta 联合开发 | 商业模式历史性转折:从"卖 IP"迈向"卖芯片"(见下) |
| 2026.02 | 英伟达清仓其持有的 Arm 股份 | 财务性退出,与业务合作无关 |

## 二、关键事件详解

**1) 软银私有化(2016)** — 孙正义以 320 亿美元溢价收购,判断"未来万物皆联网,而每个联网设备大概率跑 Arm"。私有化让 Arm 摆脱季度业绩压力,在数据中心(Neoverse)和研发上大举长期投入——这为 FY24–FY26 的 AI 增长打下基础。

**2) 英伟达收购案流产(2020–2022)** — 400 亿美元的世纪交易,因美国 FTC、英国 CMA、欧盟委员会等以"扼杀竞争/国家安全"为由强烈反对,于 2022 年 2 月取消。这直接把 Arm 推向**重新 IPO** 的道路,并促成 Rene Haas 上任。

**3) 纳斯达克重新上市(2023.09)** — 约 545 亿美元估值,是 2023 年全球最大 IPO。软银保留约九成股权,意味着**流通盘小、股价波动大**,且公司战略高度受软银意志影响。

**4) 从"卖 IP"到"卖芯片"(2026)** — 2026 年 3 月发布 **Arm AGI CPU**(136 核,面向 AI 数据中心的 agentic 工作负载),与 Meta 联合开发,预计 2026 下半年量产。这是 Arm 36 年来首次亲自下场做量产芯片,可能与部分授权客户(高通、Nvidia 等)形成竞合关系。管理层同时给出 FY2031 目标:集团营收约 250 亿美元、每股盈利超 9 美元。

**5) Arm 中国的"半独立"问题** — 2020–2022 年与 Arm 中国 CEO 吴雄昂爆发控制权纠纷(其掌握公章拒绝交权)。最终 Arm 把股权转入独立实体,得以继续在华收取授权费但无需并表。这既是历史遗留风险,也是地缘政治敞口(详见 `risk/china.md`)。

## 三、关键人物

| 人物 | 角色 | 关键贡献 |
|---|---|---|
| **Sophie Wilson & Steve Furber** | 架构与芯片设计师(Acorn 时代) | 设计首颗 ARM 处理器,奠定 RISC 低功耗基因 |
| **Robin Saxby(罗宾·萨克斯比)** | 首任 CEO / 董事长(1991 起) | 确立"IP 授权"商业模式,把小公司做成行业标准 |
| **Warren East(沃伦·伊斯特)** | CEO(2001–2013) | 带领 Arm 统治智能手机时代;后任劳斯莱斯 CEO |
| **Simon Segars(西蒙·西加斯)** | CEO(2013–2022) | 元老(效力 30 年);经历软银收购与英伟达交易 |
| **Rene Haas(雷内·哈斯)** | CEO(2022.02 至今) | 主导 2023 IPO、押注数据中心/AI、推动自研 AGI CPU |
| **孙正义(Masayoshi Son)** | 软银创始人 / Arm 大股东 | 2016 私有化操盘者;仍通过软银控股约 90% |
| **吴雄昂(Allen Wu)** | 前 Arm 中国 CEO | 2020–2022 控制权纠纷的中心人物 |

## 四、关键产品(技术演进)

- **ARM7TDMI(1990s)** — 早期爆款,随诺基亚等功能机走向全球,让 Arm 成为移动标准。
- **StrongARM / XScale** — 与 DEC、后与 Intel 合作的高性能变体(历史产品线)。
- **Cortex 系列(2004 起)** — 现代品牌三分支:
  - **Cortex-A**:高性能应用处理器(手机、平板、笔电的主力)
  - **Cortex-R**:实时/安全关键(存储、基带、汽车)
  - **Cortex-M**:超低功耗微控制器(IoT、传感器,出货量最大)
- **Mali GPU(2006 起)** — 移动图形处理器。
- **Neoverse(2018 起)** — 数据中心/云平台,N/V/E 三系(N3、V3、E3 等);顶级云厂商自研 CPU(如 AWS Graviton、Google Axion、Microsoft Cobalt)几乎都基于 Neoverse。**这是 FY24–FY26 版税增长的核心引擎**。
- **Armv9 架构(2021)** — 新一代指令集,带来更高的每颗芯片版税率(版税增长的结构性驱动)。
- **Compute Subsystems(CSS)** — 预集成、经验证的"半成品"计算子系统,客户拿来即可快速流片,单位授权价值更高。
- **C 系列(2025 品牌重组)** — 高端 CPU 统一为 C1-Nano / C1-Pro / C1-Premium / C1-Ultra(C1-Ultra 为原 X925 继任者)。
- **Arm AGI CPU(2026)** — 136 核、面向 AI 数据中心,公司**首颗自研量产芯片**,与 Meta 联合开发。

---

## 五、一句话总结

Arm 用一套"授权 + 版税"的轻资产模式,从 1990 年剑桥一间旧厂房起步,成为**全球计算的底层标准**;经历软银私有化、英伟达收购流产、2023 重新上市三次大转折后,如今正把增长引擎从**手机**切换到**数据中心/AI**,并在 2026 年首次亲自下场造芯片——这是它 36 年历史上最大的商业模式变化,也是当前投资逻辑的核心变量。
