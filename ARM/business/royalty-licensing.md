# Arm 业务详解:版税(Royalty)与授权(License)

> 整理于 2026-07-14。配套数据见同目录 `季度汇总表.csv` 与 `README_索引与要点.md`。
> 本文为公开信息整理,非投资建议。

Arm 是 IP(知识产权)授权商,自己**不生产芯片**。收入两条腿:先收**授权费**(入场券),芯片量产后再按颗收**版税**(过路费)。两者**不是二选一,而是先后叠加**——同一个客户两笔都付。

```
客户 →① 付授权费(拿到设计权/使用权)→ 设计芯片 → 流片量产 →② 每卖一颗付版税(长期持续)
```

FY2026 收入:总营收 $4.92B|版税 $2.61B(+21%)|授权 $2.31B(+25%)|年度合约价值 ACV $1.66B(+22%)。

---

## 一、版税 Royalty(后端、持续、稳)

### 机制
- 芯片量产后,**几乎每一颗出货都抽成**,不管客户走哪种授权、不管设计新旧。
- 计费方式:**按芯片平均售价(ASP)的一个百分比**,或**固定单价/颗**。
- **用的 Arm IP 越先进,单颗版税率越高**——这是版税增长的核心引擎(即便出货颗数不增,单颗更值钱):

| 技术档位 | 大致版税率(占 ASP) |
|---|---|
| Armv8 | ~2.5%–3% |
| **Armv9** | ~5%(约翻倍) |
| **CSS 计算子系统** | ~10%(再翻倍,下一代更高) |

- **长尾特性**:芯片生命周期长达 10 年以上,Arm 十几年前的老设计**至今仍在收版税**。单颗费率会随累计出货量上升而**递减**,但合同通常设**最低费率/最低单价**兜底。

### 增长逻辑(关键)
Arm 的版税增长 = **单价升级(v8→v9→CSS)× 结构升级(数据中心占比上升)**,**不是靠颗数**。手机等成熟市场颗数基本不增,但 Armv9/CSS 渗透让单颗更贵。
- FY26 数据中心版税**同比翻倍**;
- 顶级云厂商新服务器芯片中 Arm 占比**接近 50%**。

### 出货量披露(注意)
- 财报以营收为主。**单季芯片颗数仅 FY24 披露过**(约 70 亿颗/季,滞后一季、客户自报),**FY25 起停报**。
- 现在只有**累计口径**:截至 2026-03-31,**累计出货 >3500 亿颗** Arm 芯片。
- **分产品线颗数(Cortex-M / Neoverse 等)财报不披露**,需靠第三方(IDC / Counterpoint / TechInsights)估算。

## 二、授权 License(前端、一次性确认、波动大)

授权像"选套餐",取决于**要用多少 IP + 有没有自研能力 + 出货规模**。当前主要 4 种:

| 套餐 | 本质 | 适合谁 | 费用结构 | FY26末规模 |
|---|---|---|---|---|
| **Arm Flexible Access(AFA)灵活授权** | 入门级"自助餐":先低价拿一大批 IP 试验/设计 | 中小厂、初创、先试水 | 年费 ~$85k,可无限流片;**量产时才补授权费** + 版税 | ~329 家 |
| **↳ 初创版(AFA for Startups)** | AFA 免费档 | 融资<$50M、营收<$5M 的初创 | access 费全免,量产后才付 | (计入 AFA) |
| **Arm Total Access(ATA)全面授权** | 高级"全包自助餐":一次订阅拿**最新全部** CPU/GPU/系统IP+工具+支持 | 出货量大的主力芯片厂 | 较高年订阅费,**流片权已含在订阅内** + 版税 | ~56 家 |
| **单项技术授权(Technology/Product)** | "单点":只买某一个具体的核 | 只要某款特定 IP | 单笔授权费 + 版税 | — |
| **架构授权(Architecture License)** | "单点+最高自由":买指令集使用权,**允许自研兼容核** | 苹果、高通、英伟达(Grace)等巨头 | 授权费较高 + 量产照付版税 | — |

### 三个关键区别
1. **AFA vs ATA = 流片费付法不同**:AFA 便宜进门、量产时再补授权费(适合"还没定");ATA 订阅费已含流片权、拿全套最新 IP(适合"要大规模做产品")。典型路径:**AFA 试水 → 做大后升级 ATA**——这是 Arm 把客户往上引、锁定长期版税的漏斗。
2. **自助餐(AFA/ATA)vs 单点(技术/架构)**:前者给一大批 IP 的**访问权**按需取用;后者买明确的一样东西(一个核 / 自研核的权利)。
3. **无论哪种,后端都付版税**;套餐只决定"前置授权费怎么收、能取用多少 IP"。

### 收入特性(看财报要点)
- **授权收入波动大**:受大额合同**签约时点**影响,呈锯齿状(如 Q4 FY26 授权 $819M 一度**反超**版税 $671M),单季高低不代表经营持续向好。
- **授权是版税的先行指标**:今天签的授权,是在为未来 3–5 年的版税**蓄水**。判断长期价值看**版税趋势**,授权看**签约动能(客户数、ACV、RPO)**。

---

## 三、一句话总结
- **版税**:全生态出货都抽、绕不开、稳增长;靠"单颗更值钱"(v9/CSS)而非"卖更多颗"驱动。
- **授权**:4 种套餐(AFA/ATA/技术/架构),选哪种看需求与规模;波动大,是版税的领先指标。
- 看趋势盯**版税 + Armv9/CSS 渗透 + 数据中心占比**;看动能盯**授权客户数 / ACV / RPO**。
